# Practica 02 - App de Registro de Asistencia 📱

Aplicación móvil desarrollada en Android Studio para el registro rápido de usuarios mediante **Nombre** y **Matrícula**.

## 🚀 Características
- **Interfaz limpia:** Pantalla principal con formulario para ingreso de datos.
- **Acciones principales:**
  - **Registrar:** Captura los datos ingresados por el usuario.
  - **Limpiar:** Restablece los campos del formulario.
- Universidad Tecnológica de Xicotepec de Juárez

## 🛠️ Tecnologías utilizadas
- **Lenguaje:** Kotlin
- **Entorno de desarrollo:** Android Studio
- **Diseño de interfaz:** XML (ConstraintLayout / LinearLayout)
